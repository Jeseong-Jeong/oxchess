규칙

진행

P1(선공)과 P2가 번갈아 한 글자씩 O 또는 X를 놓습니다. 매번 둘 중 원하는 걸 고를 수 있고, 놓은 글자는 한 줄로 이어집니다(최대 40칸).

승리 조건

  • P1: 같은 5글자 패턴이 2번 나오면 승리
  • P2: 같은 3글자 패턴이 4번 나오면 승리
  • 하우스룰: OOO, XXX는 3번만 나와도 P2 승리
    밸런스 패치 규칙에서는 OXO, XOX도 3번
  • 두 조건이 동시에 만족되면 P2 승리
  • 40칸이 다 차면 무승부

세는 법

패턴 사이에 다른 글자가 있어도 됩니다. 다만 겹치지 않게 왼쪽부터 셉니다.

OOOOOO → OOO 2번 · OOOO → OOO 1번

체크 / 체크메이트

체크: 지금 차례인 사람이 O나 X 중 한쪽을 두면 상대가 이기는 상태.
체크메이트: 뭘 둬도 상대가 이기는 상태.

중요: 자기가 놓은 글자로 상대 조건이 완성돼도 상대가 이깁니다. 두 사람이 한 줄을 같이 쓰는 게임이에요.
