# OX체스 규칙

## 진행
- P1(선공)과 P2(후공)가 번갈아 한 칸씩 **O 또는 X**를 놓습니다. 매번 둘 중 원하는 것을 고릅니다.
- 놓은 글자는 한 줄로 이어집니다. 최대 40칸입니다.
- 두 사람이 **한 줄을 같이 씁니다.** 내가 놓은 글자로 상대 조건이 완성돼도 상대가 이깁니다.

## 승리 조건
| 누가 | 조건 |
|---|---|
| P1 | 같은 **5글자** 패턴이 **2번** 나오면 승리 |
| P2 | 같은 **3글자** 패턴이 **4번** 나오면 승리 |
| P2 (하우스룰) | `OOO`, `XXX`는 **3번**만 나와도 승리 |
| P2 (밸런스 패치, 선택) | `OXO`, `XOX`도 **3번**만 나오면 승리 |

- 두 조건이 동시에 만족되면 P2가 이깁니다.
- 40칸이 다 차도 승부가 안 나면 무승부입니다(실제로는 거의 나오지 않음).

## 패턴 세는 법
- 패턴 사이에 다른 글자가 있어도 됩니다.
- **겹치지 않게 왼쪽부터** 셉니다.
  - `OOOOOO` → OOO 2번
  - `OOOO` → OOO 1번
  - 예: `OOO X OOO XX OOO` → OOO 3번 → 하우스룰로 P2 승

## 체크 / 체크메이트
- **체크**: 지금 차례인 사람이 O나 X 중 한쪽을 두면 상대가 이기는 상태
- **체크메이트**: O를 두든 X를 두든 상대가 이기는 상태

## 규칙 프리셋
| 이름 | 내용 | 완벽하게 두면 |
|---|---|---|
| 기본 규칙 | 하우스룰 `OOO`·`XXX` 3회 | P1 필승 |
| 밸런스 패치 | 기본 규칙 + `OXO`·`XOX` 3회 | P2 필승 (둘 다 아무렇게나 두면 가장 공정: P1 47% / P2 53%) |
