# 밸런스 분석

2026-09-28 측정. 두 가지 방법으로 쟀습니다.
- **완전 탐색:** 모든 수를 끝까지 계산했습니다(`analysis/solver.py`).
- **대결 시뮬레이션:** 규칙마다 2만 판씩 뒀습니다.

승률은 **선공(P1)과 후공(P2)을 따로** 적었습니다.

## 규칙별 결과

| 규칙 | 완벽하게 두면 | 둘 다 무작위로 두면 (P1 : P2) |
|---|---|---|
| **기본 규칙** (P2 4회 / 하우스룰 3회 / P1 2회) | **P1 필승** (20수) | **65% : 35%** |
| 하우스룰 없음 | P1 필승 (20수) | 77% : 23% |
| P2 기준 5회 | P1 필승 (19수) | 80% : 20% |
| P2 기준 3회 | P2 필승 (16수) | 26% : 74% |
| 기본 규칙에서 3글자 쪽이 선공 | 5글자 쪽 필승 (19수) | 5글자 쪽 65% |
| **밸런스 패치** (+ OXO·XOX 3회) | **P2 필승** (22수) | **47% : 53%** |

## 알아낸 것
- **유불리는 차례가 아니라 승리 조건에서 나옵니다.** 기본 규칙에서 선후공을 바꿔도 5글자 쪽이 이깁니다.
- **실력 차이가 결과를 크게 좌우합니다.**
  - 완벽한 P1 vs 무작위 P2: P1 100% 승
  - 무작위 P1 vs 완벽한 P2: P2 99.3% 승
- **한 수 앞만 보는 건 무작위와 거의 차이가 없습니다.** 바로 이기면 두고 바로 지면 피하는 정도로는 부족하고, 깊이 읽어야 합니다.
- **승부는 초반에 갈립니다.**
  - 기본 규칙의 최적 수순에서는 P1의 7·9·11·13번째 수가 "정답이 하나뿐인 수"입니다.
  - 진 쪽이 처음 실수한 수는 대부분 7~9번째 수였습니다(중앙값 7번째).
- 20수가 넘는 필승 수순은 사람이 계산할 수 없습니다. 그래서 필승 게임이어도 실제 대결은 성립합니다. 오목이나 사목(Connect 4)도 선공 필승으로 풀린 게임입니다.

## 최적 수순 예시 (기본 규칙)
`OOXXXOXOXOXOXXOOXOXO` → P1 승 (OXOXO 2회, 20수)
