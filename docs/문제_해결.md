# 문제 해결

## 온라인 대전이 연결되지 않아요
1. **양쪽 다 앱을 새로고침하세요.** 가장 흔한 원인은 한쪽이 예전 버전인 경우입니다.
   - 2026-09-28에 연결 방식이 바뀌었습니다(직접 연결 → 중계 서버).
   - 버전이 다르면 서로 다른 곳에서 찾고 있어서 만나지 못합니다.
   - 지금 버전은 앱을 열 때 새 버전을 알아서 확인합니다.
2. **방 코드를 확인하세요.** 5자리이고, 헷갈리는 0·O·1·I는 쓰지 않습니다.
3. **"방을 찾을 수 없어요"가 뜨면**, 방을 만든 쪽도 새로고침한 뒤 방을 다시 만드세요.
4. 온라인 대전은 무료 공개 중계 서버(`test.mosquitto.org`, `broker.emqx.io`)를 씁니다.
   - 두 곳에 동시에 연결해서 한 곳이 죽어도 됩니다.
   - 둘 다 안 되면 잠시 뒤 다시 해 보세요.

## 폰에서 새 버전이 안 보여요
- 앱(또는 브라우저 탭)을 완전히 닫았다가 다시 여세요.
- GitHub Pages가 파일을 최대 10분 동안 캐시합니다. 배포 직후라면 10분 뒤에 다시 여세요.

## 엑셀 파일이 구글 드라이브에서 스프레드시트로 안 열려요 ("업로드할 수 없습니다")
**원인:** 이 PC에는 한컴오피스(한셀)가 설치되어 있습니다. 한셀이 `.xlsx` 파일 종류를 표준값이 아닌 `application/haansoftxlsx`로 등록해 둬서, 브라우저가 한컴 파일로 올리고 구글이 인식하지 못합니다.

**해결:** PowerShell에서 한 번 실행합니다. 내 계정에만 적용되고, 한셀로 여는 건 그대로입니다.
```powershell
Set-ItemProperty -Path 'HKCU:\Software\Classes\.xlsx' -Name 'Content Type' -Value 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
```
실행 후 크롬을 완전히 껐다 켜고 다시 올리세요. 2026-09-28에 적용했습니다. 한컴오피스를 업데이트한 뒤 다시 안 되면 한 번 더 실행하세요.

되돌리기:
```powershell
Remove-ItemProperty -Path 'HKCU:\Software\Classes\.xlsx' -Name 'Content Type'
```

## 엑셀이 없는데 수식이 맞는지 확인하고 싶어요
`python excel/verify_xlsx.py`가 파이썬 `formulas` 패키지로 엑셀 수식을 직접 계산해서 웹앱 엔진과 비교합니다. 자세한 건 [업데이트_방법.md](업데이트_방법.md)를 보세요.
