# 업데이트 방법

이 프로젝트를 이어서 고칠 때 보는 문서입니다. Claude에게 맡길 때는 "docs 폴더의 업데이트_방법.md를 읽고 시작해"라고 하면 됩니다.

## 어디에 뭐가 있나
| 무엇 | 위치 |
|---|---|
| 웹앱 (실제 서비스) | https://jeseong-jeong.github.io/oxchess/ |
| 코드 저장소 (공개) | https://github.com/Jeseong-Jeong/oxchess |
| 이 PC의 작업 폴더 | `C:\Users\user\Desktop\main\oxchess` |
| 웹앱 소스 | `app/` (engine.js 엔진+AI, app.js 화면, net.js 온라인, sw.js 오프라인) |
| 분석 스크립트 | `analysis/` |
| 엑셀 도구 | `excel/` (엑셀 파일 자체는 저장소에 올리지 않음) |
| 문서 | `docs/` |
| 드라이브용 폴더 만들기 | `tools/make_share.py` |

필요한 프로그램은 node, 파이썬(`%LOCALAPPDATA%\Programs\Python\Python313\python.exe`), git, GitHub CLI(`C:\Program Files\GitHub CLI\gh.exe`)입니다.

## 웹앱 고치기
1. **로컬에서 실행**
   ```bash
   python -m http.server 5173 --directory app
   ```
   http://localhost:5173 을 엽니다.
2. **AI나 규칙을 바꿨다면 검증**
   ```bash
   node analysis/test_god.js 300    # 신이 P1이면 절대 안 지는지 (반드시 "✅ 전부 통과")
   node analysis/ai_levels.js 500   # 난이도 순서 하수 < 중수 < 고수 < 신 유지되는지
   ```
   승률은 **선공과 후공을 따로** 보고 판단합니다.
3. **버전 번호 올리기 (필수)**
   - `app/index.html`의 `?v=숫자` 4곳과 `app/sw.js`의 `CACHE = 'oxchess-v숫자'`를 같이 올립니다.
   - 안 올리면 폰에 예전 파일과 새 파일이 섞여서 이상하게 보일 수 있습니다. 예: 난이도가 undefined로 표시됨.
4. **배포**
   ```bash
   git add -A
   git commit -m "무엇을 바꿨는지"
   git push origin main
   git push origin `git subtree split --prefix app main`:refs/heads/gh-pages --force
   ```
   1~2분 뒤 사이트에 반영됩니다. 폰 앱은 다시 열면 새 버전을 알아서 불러옵니다(게임 중이면 "새 버전이 있어요" 알림).

## 엑셀 고치기
- 최신 파일은 `OX chess_v3.xlsx`입니다. 원본 기획 파일 `OX체스.xlsx`(v1)와 `OX chess_v2.xlsx`는 그대로 둡니다.
- 새 버전은 v3를 **복사해서** `OX chess_v4.xlsx`처럼 이름을 바꾼 뒤 고칩니다.
- 시트 구성
  - **OX체스:** 입력 칸 `B10:AO10`(한 줄 40칸), 규칙 선택 `W6`(기본 규칙 / 밸런스 패치)
  - **규칙, 공략:** 설명 텍스트
  - **계산:** 자동 계산(수정 금지)
    - `B3:B5` 기준 횟수: P2 4회, 하우스룰 3회, P1 2회
    - `B6` 규칙 스위치
    - 32~39행: 현재 3글자 패턴
    - 40~71행: 현재 5글자 패턴
    - 72~111행: O를 둔 뒤
    - 112~151행: X를 둔 뒤
- **검증 (엑셀 없이):**
  ```bash
  python excel/verify_xlsx.py "OX chess_v3.xlsx"
  ```
  웹앱 엔진과 16판을 대조합니다. "불일치 0 건"이 나와야 합니다. 약 7분 걸립니다.
- v3를 어떻게 만들었는지는 `excel/build_v3.py`에 기록돼 있습니다.

## 드라이브 공유 폴더 다시 만들기
```bash
python tools/make_share.py
```
`드라이브_업로드/OX체스/` 폴더가 새로 만들어집니다. 문서, 엑셀, 소스코드 zip이 들어 있어요. 이 폴더를 구글 드라이브에 끌어다 놓으면 됩니다.
- **같은 파일을 새 내용으로 바꿀 때:** 드라이브에서 파일을 오른쪽 클릭 → **파일 정보 → 버전 관리 → 새 버전 업로드**를 쓰면 공유 링크가 그대로 유지됩니다.
- **엑셀이 스프레드시트로 안 열리면:** [문제_해결.md](문제_해결.md)의 "한컴오피스" 항목을 보세요.
